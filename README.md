# 🤖 AI Trading Agent

A full-stack autonomous AI trading agent that uses machine learning and technical analysis to make trading decisions in real-time.

## 🚀 Features

- **🤖 Autonomous Trading** - AI makes trading decisions using ML models
- **📊 Real-time Data** - Live market data from Yahoo Finance
- **🧠 Machine Learning** - Random Forest models for price prediction
- **📈 Technical Analysis** - RSI, MACD, Bollinger Bands, and more
- **🛡️ Risk Management** - Position sizing and stop-loss protection
- **💻 Web Dashboard** - React frontend with real-time charts
- **📱 Responsive Design** - Works on desktop and mobile

## 🏗️ Architecture
Frontend (React) ←→ API (Flask) ←→ Trading Agent (Python)
